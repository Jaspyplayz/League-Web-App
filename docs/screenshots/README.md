## Retaking them

- Use a desktop browser window about 1280 px wide, on the live site, and crop to just the content (no browser chrome or empty margins).
- Keep each PNG under about 500 KB so the README loads quickly. Reducing to 256 colors works well for these flat, dark screens; [Squoosh](https://squoosh.app) can do it.
- Keep the same file names and the README picks the new images up.
