# Screenshots

Images for the main [README](../../README.md). Add them once the UI is polished and showing real data.

## Shot list

| File | What to capture | Where it goes in the README |
|---|---|---|
| `match-analysis.png` | A match page with the gold difference chart and turning points visible. This is the hero shot, so pick a game with a clear swing. | Top of the README, under the live link |
| `player-profile.png` | A player profile with rank and the recent matches list | Features section |
| `search.png` | The home page search | Features section (optional) |
| `demo.gif` | Search a player, open a match, scroll to turning points (under 15 seconds) | Top of the README, instead of `match-analysis.png` if it reads well |

## Tips

- Use a desktop browser window about 1280 px wide, and crop out the browser chrome.
- Use a well-known public player so recruiters can reproduce it on the live site.
- Keep each PNG under about 500 KB so the README loads quickly. [Squoosh](https://squoosh.app) works well.
- After adding a file, replace the "Screenshots coming soon" line in the README with an image link, for example `![Match analysis](docs/screenshots/match-analysis.png)`.
